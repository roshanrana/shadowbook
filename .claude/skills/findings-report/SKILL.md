# FINDINGS.md

Generated by `make report` from run artefacts. Never hand-edited. If a sentence needs changing, change the template.

## Structure (fixed)

1. **Header** — git SHA, seed, broker and versions, machine, date. Everything needed to reproduce.
2. **Finding 1 — Time-to-discovery per quirk.** One row per quirk in `legacy-sim/quirks.yaml`: `id · name · cadence · first detected (business day #) · grain · breaks at first detection · breaks to isolate · detected? (Y/N)`. Undetected quirks are shown, not hidden — they are the most important rows.
3. **Finding 2 — Delivery-semantics ablation.** One row per config A–D, median of ≥ 3 runs with min–max: `config · sent · applied · lost · duplicated · p50 · p95 · p99 · lag peak · drain s · invariant held`.
4. **Methods.** Load profile, generator and why it is open-model, chaos schedule as executed, how loss/duplication are counted, grains and classification (link to LLD §), run counts.
5. **What this does not prove.** Mandatory: quirks are seeded and known (calibration, not discovery); a simulator is not a core; single-box numbers are not production numbers; D's guarantee ends at the database boundary; portfolio work, not a production system.
6. **Reproduce.** Exact commands.

## Style

Tables first, prose second. Units on every number. No adjectives about results. Optional LLM narrative (`--narrative`, default off) appears only in a block labelled "Suggested narrative (LLM-drafted, unverified)".

## Determinism

`make report` run twice on the same artefacts produces byte-identical output. A test asserts this.
